# 10. “Tell me about a difficult production incident.”

Use the **STAR format**:

**Situation → Task → Action → Result**

For example:

> In one production release, there was an issue affecting application deployment. My responsibility was to identify whether the problem was related to the application, pipeline, infrastructure or deployment environment.
>
> I first checked the pipeline logs and compared the failed deployment with the last successful deployment. Then I checked the application logs, infrastructure status and recent configuration changes.
>
> I coordinated with the development and QA teams while investigating the infrastructure and deployment side. Once the root cause was identified, we applied the required correction and validated the deployment.
>
> After restoring the service, I documented the RCA and identified preventive actions so that the same issue would be less likely to happen in future releases.

**Important:** Replace this with a real incident from your experience before using it in an interview. Don't invent a production incident.
